# ZySU Releases

Official public downloads for ZySU. Development and build workflows are maintained in a separate private repository.

- [Download the latest stable version](https://github.com/wuluoy-creator/ZySU-Releases/releases/latest)
- [All releases](https://github.com/wuluoy-creator/ZySU-Releases/releases)
- [Report an issue](https://github.com/wuluoy-creator/ZySU-Releases/issues)

Release assets include the signed Manager APK, ksud, kernel modules, and `update.json`.

## Updating from an older installation

Versions through v3.3.1 check the old repository for updates. Install a newer APK that supports this release repository once to switch update sources. Migrated v3.3.0/v3.3.1 APKs are unchanged and still use the old update source.
