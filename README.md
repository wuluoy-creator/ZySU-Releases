ZySU 的源码、版本发布、更新下载和问题反馈现已统一到 **[wuluoy-creator/ZySU](https://github.com/wuluoy-creator/ZySU)**。

本仓库已归档，不再发布新版本。v3.3.3、v3.3.4 的发布说明和全部附件已迁入主仓库，并按 SHA-256 校验一致；这里保留历史下载，供旧链接使用。原有问题已转移至主仓库。

旧版 Manager APK 内置的更新地址不会随仓库迁移自动变化。请从主仓库下载并安装包含新地址的后续版本一次；此后更新检查使用主仓库。迁移过来的历史 APK 保持原始内容，重新安装它们不会切换内置更新地址。

This repository is archived and will receive no new releases. Release notes and all assets for v3.3.3 and v3.3.4 have been copied to the main repository and verified by SHA-256. Historical downloads remain here for existing links, and existing issues have moved to the main repository.

Older Manager APKs retain their built-in update URL. Install a subsequent build containing the new URL from the main repository once to switch future update checks. Migrated historical APKs are unchanged; reinstalling them does not change their update URL.
